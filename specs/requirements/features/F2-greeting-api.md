# Greeting API

## Purpose

An endpoint that returns the hello message to signed-in callers.

## User Stories

- F2.1 As a signed-in user, I get the hello message from the API.
- F2.2 As a caller who is not signed in, I am rejected as unauthorized.

## Decisions

- The message is always the fixed text "Hello, World!".

## Out of Scope

- A health-check endpoint.
